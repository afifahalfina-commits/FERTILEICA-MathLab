# FERTILEICA MathLab
Website statis (HTML/CSS/JS) + Supabase + Netlify.

1. Supabase: buat project, jalankan `supabase.sql`, salin Project URL dan anon key ke `config.js`.
2. GitHub: buat repo, upload semua file ini (atau `git init && git add . && git commit && git push`).
3. Netlify: Add new site > Import from Git > pilih repo (build command kosong, publish directory `.`).
4. Data siswa: Supabase > Table Editor > submissions > Export CSV.
5. Ganti soal contoh di `soal.js` dengan instrumen yang sudah divalidasi.
